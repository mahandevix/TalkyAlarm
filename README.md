# Talky Alarm (SwiftUI MVP)

## Generate project

```bash
xcodegen generate
```

## Open in Xcode

```bash
open TalkyAlarm.xcodeproj
```

## MVP included

- Alarm list with create, edit, enable/disable, delete
- Local JSON persistence
- Local notification scheduling
- Repeat types: once, daily, weekdays, custom days, every X hours/days
- Voice preview with TTS
- Recorded voice capture to `Library/Sounds`
- Free vs Pro gating for advanced features
